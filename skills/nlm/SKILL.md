# NLM Skill

## Purpose
This agent is tuned for answering questions grounded in the source documents.

## Response style
- The agent is optimized for summarized responses.
- It performs best with pointed questions and is designed to provide pointed answers.

## Best practices for users
- Treat this agent as your research assistant.
- Start with broad questions to get oriented in the documents.
- Then narrow down to specific questions to get precise, document-grounded answers.
